# 마인크래프트 서버 상태 봇

마인크래프트 서버(Aternos 등)가 열려있는지 닫혀있는지 디스코드 채널의 메시지 하나로 보여주는 봇입니다.
메시지는 새로 보내지 않고 계속 수정해요. 서버(길드)마다 따로 설정할 수 있어요.

## 명령어

| 명령어 | 설명 |
|---|---|
| `/마인크래프트 서버 상태설정` | 상태 표시 채널과 서버 주소를 설정해요 |
| `/마인크래프트 서버 상태삭제` | 설정과 상태 메시지를 지워요 |

두 명령어 모두 **서버 관리** 권한이 있는 사람만 쓸 수 있어요.

### 상태설정 옵션

| 옵션 | 설명 |
|---|---|
| `채널` | **생성**: 봇이 `마크서버-상태` 채널을 만들어요 (다른 사람은 글을 쓸 수 없어요). **설정**: 이미 있는 채널을 고르는 창이 떠요 |
| `주소` | 마인크래프트 서버 주소. `abc.aternos.me` 또는 `abc.aternos.me:12345` (포트를 안 쓰면 25565) |
| `챗커스텀` | `True`면 상태 표시를 꾸미는 창이 떠요. 기본값은 `False` |
| `이름` | (선택) 상태 메시지 제목에 쓸 서버 이름. 비우면 주소를 써요 |

### 꾸미기 창 (챗커스텀: True)

- **표시할 항목**: 접속자 수, 접속 중인 플레이어 목록, 서버 주소, 버전, 응답 속도, 마지막 업데이트 시간
- **문구 편집**: 제목, 열림/닫힘/켜지는 중 문구, 추가 설명
- **색상 편집**: 열림/닫힘/켜지는 중 색상 (예: `57F287`)
- **미리보기 상태 바꾸기**: 열림 → 켜지는 중 → 닫힘 순서로 미리보기를 바꿔 봐요
- **완료**를 눌러야 저장돼요

## 봇 초대

[개발자 포털](https://discord.com/developers/applications) → **OAuth2 → URL Generator**

- Scopes: `bot`, `applications.commands`
- Bot Permissions: 채널 보기, 메시지 보내기, 링크 첨부, 메시지 기록 보기, **채널 관리** (채널 '생성'을 쓸 때만)

슬래시 명령어가 안 보이면 위 링크로 봇을 다시 초대해 보세요.

## 실행 방법

1. `.env.example`을 `.env`로 복사한 뒤 `DISCORD_TOKEN`을 채웁니다.
2. 설치 후 실행합니다.

```bash
pip install -r requirements.txt
python bot.py
```

설정은 `config.json`에 저장돼요. 봇을 껐다 켜도 유지됩니다.

## 설정 값 (`bot.py` 위쪽)

- `CHECK_INTERVAL`: 서버 확인 주기(초). 기본 60
- `EDIT_ONLY_ON_CHANGE`: `True`면 상태가 바뀔 때만 메시지 수정, `False`면 확인할 때마다 수정

## 주의

- `.env`(토큰)와 `config.json`은 GitHub에 올리지 마세요. `.gitignore`에 이미 들어 있습니다.
- 봇이 계속 동작하려면 봇을 실행하는 컴퓨터(또는 호스팅)가 켜져 있어야 합니다.
- 내부망이나 자기 자신을 가리키는 주소는 보안 때문에 쓸 수 없어요.
